Generated with Pillow: `ImageOps.grayscale(Image.open(source)).resize((256, 256), Image.Resampling.LANCZOS).tobytes()`.

`orchester-alpha.png` is the lossless source-resolution portrait matte. `orchester.alpha` is its 256 × 256 row-major 8-bit thumbnail, generated by `extract-portrait.py` with rembg's IS-Net anime segmentation model. The model only extracts transparency; the original face, hair, ears, clothes, composition and RGB are not redrawn. The script records the model checksum and tool versions. Neither the model nor Python is needed at runtime.

The renderer weights grayscale pixels by this matte while scaling down. Transparent areas emit spaces or a single upper/lower half-block with the terminal's default background, so no rectangular background is painted. Luminance stays in neutral gray levels 24–144, keeping highlights visibly gray instead of white. Up to 128 × 128 display pixels fit the available terminal; a 180 × 40 viewport uses about 60 × 60 pixels. No external image protocol or runtime file path is required.
