# 导航、管理功能与 Windows 0.1.7 验收

日期：2026-10-10。桌面版本：0.1.7，Windows x64。

## 本轮结果

左侧导航上方依次为 Home、定时任务、插件；底部从下往上依次为设置、主题、宠物。导航在管理页面仍然可用。原底部面板及对应菜单、设置入口已移除。

输入框采用参考图中的圆角灰色输入区域，下方左侧为附件和权限，右侧为运行状态、模型与推理强度、语音和粉色发送/停止按钮。模型与权限显示真实选择；未配置模型时保留设置入口。附件支持受大小限制的文本文件，内容插入可编辑草稿；语音输入使用系统 Web Speech 能力，不支持时禁用，不自动申请麦克风权限。

定时任务支持创建、编辑、暂停、启用、删除、立即运行、运行历史和停止当前运行。任务按工作区存入本机 SQLite，创建和编辑时保存当前模型选择。程序需要保持运行，包括托盘状态；重启后补跑一次到期任务，不补发全部错过的周期。一次性任务领取后关闭，相同任务不能并发执行。运行与手动对话共用实际执行路径，未配置模型或执行错误会记录失败。

插件页提供 Claude、Codex、OpenCode 适配器的安装、状态刷新和移除，并显示已发现的项目插件。安装复用命令行的固定版本下载、禁用安装脚本、压缩包校验和收据机制；只允许移除本程序管理的插件。项目插件只读。实际使用适配器仍需要相应的底层命令行工具。

实现与接口约定见 [管理功能设计](10-navigation-schedules-plugins-composer.md) 和 [OpenAPI](../management.openapi.yaml)。

验收发现并修复了两个运行问题：首次创建任务数据库时，需要先建立私有状态目录和私有数据库文件，才能被共用运行存储安全打开；Windows 标准 npm 启动器的脚本路径通过变量指定，需要直接解析其已验证的 Node 入口，而不是执行 shell。两处修复均增加回归测试并重新通过真实操作验收。
