# 模型设置与 Windows 0.1.4 验收

日期：2026-10-01。桌面版本：0.1.4，Windows x64。

## 交付行为

未配置模型时，输入框中的“设置模型”直接进入提供商设置。目录加载期间显示加载状态；加载失败时提供重试入口，已有目录刷新失败时保留上次选择，并在菜单中提供刷新和设置入口。

提供商设置支持添加服务名称、地址、API 协议、模型名称和密钥，保存后使用后端返回的实际目录。密钥输入在提交开始和取消时清空，不进入 Pinia 持久状态或浏览器存储。Windows 使用现有系统凭据库，配置文件仅写入 `${secret:provider-id}` 引用，并保留原文件的注释和备份。

新增 `POST /api/v1/models/providers`。请求限制为 32 KiB，拒绝非法字段、未知协议和重复 provider id。写入任务在阻塞线程执行，并按运行时实例串行处理。保存新默认值后清除之前的会话模型覆盖。端点自身要求本机 Host、匹配的 Origin、有效会话和 CSRF，即使脱离桌面的外层中间件也保持这些检查。

保留前一版的 Codex 风格工作区、输入框高度约束和侧栏布局。新增表单使用桌面双列、窄屏单列布局。模型设置按钮的图标和文字保持横排。
