# 手机端参考 UI、设备项目与 Agent 工作栏

当前手机端采用「控制台、任务、项目、设置」四个一级页面，借用 `sample/` 中八张手机截图的深色分层、大圆角、设置分组和底部导航结构。任务记录归入任务页，设备、主题与关于归入设置子页。多台电脑分别维护连接、项目目录和任务状态；用户选择真实项目与 Agent 后，在独立工作栏中输入任务、选择电脑文件并查看回复。

日期：2026-11-09。上述多设备界面和六套主题已在源码实现；本轮 5 个测试文件、54 项测试及 `vue-tsc --noEmit` 通过。当前多设备、目录/文件与双栏版本的 Android 原生交互正在验收，本文列出待核实场景。此前 [远程验收记录](27-remote-acceptance.md) 中 Android 16 模拟器、Keystore/HTTP 桥接与真实 Codex 的结果属于旧参考版本，不能作为本轮新 UI 已完成原生验收的证明。[远程控制设计](26-remote-control.md) 与 [iOS 启动与凭据说明](28-ios-launch-and-credentials.md) 保留原记录；iOS 尚未在 macOS/Xcode 编译或安装，物理手机尚未验收。

## 本次选择器与启动体验

全部三个原生下拉框已替换为主题化底部选择面板：任务设备筛选、项目设备选择和工作栏任务选择。面板显示完整设备地址、文字连接状态与选中勾，长列表独立滚动；支持方向键、Home/End、Tab 循环、Escape、浏览器返回、遮罩关闭和焦点恢复。忘记当前筛选设备后回到全部设备。

应用图标使用桌面 PNG 同源生成 Android/iOS 图标及 Web 品牌图。冷启动显示轻量品牌过渡，应用数据同时加载；后台恢复不重播，减少动态效果偏好会缩短并取消动画。

## 页面与实际状态

| 一级页面 | 内容和操作 |
| --- | --- |
| 控制台 | 每台电脑的名称、地址、连接状态、项目数、运行中任务数及任务总数；进入该设备项目/任务，连接新设备或重连 |
| 任务 | 多个独立 Agent 工作栏、单栏/双栏切换、各设备任务记录与设备筛选；工作栏内包含 prompt、附件、续接、输出和生命周期操作 |
| 项目 | 按设备展示项目名称与真实路径；浏览电脑允许的目录、选择现存目录添加项目，再选 Agent 打开工作栏 |
| 设置 | 「电脑设备 / 主题 / 关于」子页与单栏/双栏偏好；从设置进入子页后有返回按钮，底部「设置」保持选中 |

控制台每张设备卡片的数据来自该 host 的 `projects` 与 `runs`；运行中数量只计算 `state === 'running'`，任务数包含所有状态。连接状态来自各自 `connectionStatus`，显示「未连接 / 正在连接 / 已连接 / 正在重连 / 需要配对」。未连通设备的统计显示「—」，保存过地址不等于已连接。全局刷新及 5 秒 host 刷新读取各设备项目与任务，不合并不同电脑的状态。

任务页的设备筛选可显示全部设备或某一设备的下方任务记录，已打开工作栏仍全部呈现；列表按电脑分组，当前实现没有「全部 / 运行中 / 已完成」状态筛选。`completed`、`failed`、`cancelled` 和 `interrupted` 分别显示「已完成 / 失败 / 已停止 / 已中断」。工作栏从对应项目历史中再按 Agent 筛选任务，任务详情保留完整 prompt 与输出。

工作栏以 `(hostAddress, projectId, agent)` 标识，默认双栏、可切单栏，最多 12 栏；每栏具有自己的请求客户端、草稿、附件、选中任务、续接标识、输出游标和轮询。重复打开同一组合复用工作栏；不同电脑可以使用相同项目 ID 和任务 ID，状态仍独立。切换一级页面保留工作栏状态。关闭栏清理本地 scope 与对应偏好，不向电脑发送 cancel 或 DELETE。

点击任务显示详情与运行输出。运行中任务提供停止；终态任务可删除。继续会话要求任务已结束、项目匹配、Agent 可用并声明 `supports_resume`，且记录具有 `session_id`；进入对应工作栏后输入续接内容并发送新记录。失败说明沿用 `presentation.ts` 的错误映射。没有事件时，运行中显示等待输出，终态显示「任务已结束，没有可显示的输出」。

项目浏览使用真实 `/folders` 与 `/projects` 响应，支持输入电脑绝对路径、可访问根目录、上一级和分页；「使用此文件夹」注册已存在目录，不在手机生成虚拟项目。工作栏中的「文件 / 选文件」使用相同目录浏览器选择文件，并将路径列表附加到本栏 prompt，供电脑 Agent 使用，不上传文件内容。目录访问范围由服务的工作区与重复 `--allow-root` 参数约束；Agent 必须在电脑安装并完成所需模型登录，手机不提供模拟模型或代替 CLI 登录。

电脑设备页保留 IP 或 HTTP(S) 地址、手机名称与一次性配对码表单，并管理多台设备。配对成功清空配对码，后续访问使用令牌；重新配对仅更新该电脑的客户端。Android 凭据插件使用 Keystore 加密存储，iOS 工程包含 Keychain 实现；浏览器凭据只保留在当前页面内存中，刷新后需要重新配对。地址和电脑名称保存到 `orchester.devices`，主题保存到 `orchester.theme`，单栏/双栏保存到 `orchester.panel-columns`。

`orchester.panels` 仅保存 `{hostAddress, projectId, agent}`，不保存任务草稿、附件、会话 ID、输出或令牌。挂载时最多并发重连 4 台已保存电脑，在每台连接成功后读取项目与任务并恢复可用工作栏；其他离线电脑的偏好保留，待重连后恢复。恢复时选中该项目与 Agent 的已有任务，而不是保存旧任务响应。“忘记”清除该设备本机凭据与工作栏，不代表撤销服务端令牌。

关于页只显示项目自身的名称、功能说明和能够从当前项目确认的信息，不使用参考产品名称或虚构版本、作者和发布状态。

| `apps/mobile/src/composables/use-remote-fleet.ts` | 多 host 与工作栏生命周期、并发重连、元数据恢复、设备刷新和独立 scope 清理 |

`App.vue` 持有一个 `useRemoteFleet()`；fleet 为每台 host 与每个工作栏建立独立 `useRemoteControl()` 和 scope，沿用既有远程请求逻辑。导航只改变可见页面；关闭栏、忘记设备与 App 释放时分别清理对应 scope。共享的设备保存基于最新本地记录更新当前 host，其他 controller 的旧快照不能复活已经忘记的设备。

已有异步行为需要继续成立：

1. 切换电脑、项目或任务后丢弃旧请求响应，地址、Agent、记录和输出不能串入新目标；已经关闭或释放的工作栏不能由迟到响应恢复。
2. 同内容提交失败重试复用幂等键；等待提交响应期间编辑的新草稿不被旧响应清空。
3. 已接受的 POST 任务保留在本地记录中，即使随后的历史刷新失败或返回旧数据。
4. 输出到达终态后继续读取尾页，直到没有事件；断线从已有游标重试，电脑任务继续运行。
5. 轮询成功只清除自己的断线提示，不能清除配对、提交、取消等用户操作错误。
6. 401 进入「需要配对」并停止重复认证轮询；404 任务被删除时清除相应选中项；服务重启的中断状态正常显示。
7. 切换任务及 scope 释放清理对应定时器，其他栏继续轮询；仅显式停止操作取消远程任务。

本轮 54 项测试包含 5 项 `fleet.test.ts` 测试：同项目/任务 ID 跨设备及多项目/Agent 隔离；附件与续接仅提交到目标 host/project；关闭/卸载不取消远程任务；跨 controller 保存与忘记设备；离线偏好、仅元数据恢复及迟到输出清理。测试挂载真实 Vue composable 并使用隔离 HTTP/凭据 fixture；它们验证客户端状态与协议调用，不代表 Android/iOS 原生桥接或真实模型调用通过。

| 从不同设备、项目与 Agent 打开工作栏，切换单栏/双栏 | 同时显示各栏；输入与输出互不串用，导航后草稿保留；设置偏好重启恢复 |

| 进入输出详情或工作栏，等待完成、停止或继续会话 | 完整输出与中文状态正确；只有实际支持续接且已结束的匹配项目任务可继续 |
